# Calculadora Java y HTML

## Descripción
Aplicación web desarrollada con Java y HTML que permite realizar cuatro operaciones matemáticas: suma, resta, multiplicación y potencias.

## Operaciones disponibles
- Suma
- Resta
- Multiplicación
- Potencias

## Ramas del proyecto
- **main:** rama principal y merges.
- **frontend:** contiene los archivos HTML.
- **backend:** contiene los archivos Java.

## Comandos utilizados

1. `git init` - Inicializar el repositorio.
2. `git branch -M main` - Establecer la rama principal.
3. `git add README.md` - Añadir el README.
4. `git commit -m "Inicializar repositorio"` - Primer commit.
5. `git switch -c frontend` - Crear la rama frontend.
6. `git switch main` - Volver a main.
7. `git switch -c backend` - Crear la rama backend.
8. `git branch` - Comprobar las ramas.
9. `git switch frontend` - Cambiar a frontend.
10. `git add index.html` - Añadir el HTML.
11. `git commit -m "Crear interfaz HTML de calculadora"` - Guardar cambios.
12. `git switch backend` - Cambiar a backend.
13. `git add CalculadoraServer.java` - Añadir el Java.
14. `git commit -m "Implementar operaciones matemáticas en Java"` - Guardar cambios.
15. `git switch main` - Volver a main.
16. `git merge frontend` - Unir frontend.
17. `git merge backend` - Unir backend.
18. `git remote add origin URL` - Conectar GitHub.
19. `git push -u origin main` - Publicar main.
20. `git push -u origin frontend` - Publicar frontend.
21. `git push -u origin backend` - Publicar backend.
